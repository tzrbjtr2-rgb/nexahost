# NexaHost — projeto inicial

Site demonstrativo para uma pequena empresa de criação e publicação de sites.

## Arquivos
- `index.html`: conteúdo e estrutura da página.
- `style.css`: estilo responsivo.
- `script.js`: menu móvel e pequenas interações.
- `.github/dependabot.yml`: verifica atualizações das GitHub Actions.
- `SECURITY.md`: regras básicas de segurança do projeto.

## Como testar no Windows
1. Extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` e use a extensão Live Server, se já a tiver instalada; ou abra o arquivo diretamente no navegador.
4. Confira a página em tamanho de computador e celular.

## Antes de publicar
- Troque o nome provisório após verificar disponibilidade.
- Adicione um e-mail comercial ou link de contato que você controla.
- Não invente depoimentos, clientes ou certificações.
- Não publique dados pessoais ou segredos.
- Revise texto, acessibilidade e visual no celular.

## Segurança: próximos passos
1. Suba o projeto para um repositório GitHub.
2. Em um repositório elegível, configure o CodeQL/code scanning pela área Security do GitHub.
3. Confira os alertas do Dependabot quando houver dependências compatíveis.
4. Publique o site numa plataforma adequada a conteúdo estático.
5. Verifique quais estatísticas e registros a plataforma realmente oferece.
6. Só prometa monitoramento de segurança depois de implementar e testar os controles.

## Limites importantes
Esta primeira versão é apenas um site estático. O painel de segurança da página é ilustrativo e não executa varreduras. A análise de código, a telemetria de acessos e a interpretação por IA precisam ser configuradas separadamente. Não use este projeto para armazenar senhas, processar pagamentos ou receber dados sensíveis.
