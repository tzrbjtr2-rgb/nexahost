# Política de segurança do projeto

Este é um projeto inicial e ainda não oferece monitoramento contínuo nem garantia de segurança.

## Como reportar um problema
Não publique detalhes de uma vulnerabilidade em uma issue pública. Para um projeto comercial, configure um endereço de contato privado antes de convidar clientes ou aceitar dados reais.

## Regras de desenvolvimento
- Nunca envie senhas, tokens, chaves de API ou dados pessoais para o repositório.
- Revise alertas antes de aplicar correções.
- Teste mudanças antes de publicar.
- Mantenha cópias de segurança quando houver conteúdo de clientes.
- Use apenas testes autorizados em sistemas próprios ou em que tenha permissão explícita.
- Não prometa proteção total: verificações automatizadas podem deixar problemas passar.

## Estado atual
O site é uma demonstração estática. Não há backend, autenticação, base de dados, varredura em tempo real ou sistema de bloqueio automático.
